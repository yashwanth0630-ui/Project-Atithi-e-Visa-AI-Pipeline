# Tech Stack & Dependencies

## Frontend & Framework
- **Framework:** Next.js 14+ (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Lucide React (Clean, accessible, mobile-first design)
- **Client Utilities:** Canvas API (image cropping, resolution inspection), jsPDF (client-side synthetic ETA certificate export)

## Backend & API
- **Runtime:** Node.js Serverless (Next.js API Routes)
- **Validation Engine:** Zod (Type-safe schema definition and runtime parsing)
- **AI SDK:** Official OpenAI Node.js SDK (`openai`)

## Deployment & Hosting
- **Platform:** Vercel
- **Environment Variables:** `OPENAI_API_KEY`
